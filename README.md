# погода

Веб-приложение, показывающее текущую погоду и место на карте по введённым широте и долготе.
Написано на чистом HTML/CSS/JavaScript (ES-модули), без библиотек и фреймворков.

# возможности

- Ввод широты (−90…90) и долготы (−180…180); принимается и точка, и запятая.
- Валидация: пустые значения, не числа и выход за диапазон — ошибка под полем, поле подсвечивается.
- Данные запрашиваются через `fetch` + `async/await` из [Open-Meteo](https://open-meteo.com) (без ключа).
- Показаны температура, описание, скорость ветра, влажность и местное время в точке.
- Иконка меняется в зависимости от погоды (солнце, облака, туман, дождь, снег, гроза) и времени суток.
- Карта OpenStreetMap с маркером в нужной точке (через `iframe`, без библиотек).
- Можно добавлять сколько угодно виджетов; каждый удаляется кнопкой «×».
- Обработка ошибок сети и API.

Все функции короче 25 строк.

# запуск локально

ES-модули не работают с `file://`, нужен любой сервер

```bash
python3 -m http.server 8080
```

# деплой на сервер

На сервере с установленным Docker:

```bash
git clone <url-репозитория> && cd weather-app
docker compose up -d --build
```

Приложение будет доступно по `http://<адрес-сервера>/`.
Без Docker: скопируйте файлы в `/var/www/weather`, а `nginx.conf` — в `/etc/nginx/conf.d/`
(замените `root` на `/var/www/weather`) и выполните `nginx -s reload`.
